# STATUS

> 매 바퀴가 끝날 때 갱신한다. 사실, 검증 결과, 다음 한 가지를 짧게 남긴다.

## 현재 상태

- CQ/PQ 공용 판정 엔진이 `src/game/showdown-engine.js`로 분리되어 게임 본체와 테스트가 같은 모듈을 import한다.
- 역할 선택 화면에서 성장·정규 이닝을 건너뛰고 즉시 한 타석만 진행하는 `CORE TEST`에 진입할 수 있다.
- 한 타석 종료 뒤 네 가지 재미 검증 질문에 답하면 결과가 브라우저 로컬 저장소에 누적되고 JSON으로 내려받을 수 있다.
- 코어 테스트 질문·결과 생성·로컬 저장소 읽기/추가·JSON 직렬화가 `src/game/core-test-results.js` 순수 모듈로 분리되어 UI와 테스트가 같은 경로를 사용한다.
- Random / MaxProb / Pattern / PowerSpam 네 고정 시드 정책봇이 실제 CQ/PQ와 PUBLIC/TRUE INTENT 공용 모듈을 사용하며 지배전략 회귀를 검사한다.
- POWER는 정확한 READ에서만 PQ 보너스를 받고, 오독 시 더 큰 CQ 대가를 치른다. 실제 POWER 존 카드도 이 경로에 연결되어 있다.
- 프로덕션 빌드는 애플리케이션 코드와 외부 의존성을 별도 청크로 분리해 500 kB 초과 청크 경고 없이 생성된다.
- happy-dom과 Testing Library로 실제 React 화면을 렌더링해 튜토리얼 건너뛰기 → `CORE TEST` 진입 → 한 타석 종료 → 네 문항 저장 → 다음 플레이어 → JSON 다운로드를 클릭 회귀 검사한다.
- 인간 3인 플레이테스트의 실제 응답 수집은 아직 진행하지 않았다.

## 마지막으로 완료한 한 가지

- 실제 React UI에서 4볼로 한 타석을 끝내고 네 문항 응답·메모·로컬 저장·다음 플레이어 초기화·JSON 다운로드까지 클릭하는 후반 회귀 테스트를 추가했다 (`b34932a`).

## 검증 결과

- 자동 검사: `pnpm test` 13/13 통과, `pnpm run build` 통과, `git diff --check` 통과. 빌드에서 500 kB 초과 청크 경고가 발생하지 않았다.
- 정책 보고서: 3,000타석/정책에서 PowerSpam TB/PA 0.709, 최선 비파워 Pattern 0.694로 비율 1.022이며 1.05 상한을 통과했다. PowerSpam 접촉률 0.552는 MaxProb 0.691보다 낮고, Pattern DEEP READ 0.015는 MaxProb 0.006보다 높다.
- UI 회귀: happy-dom에서 4회 투구를 실제로 지켜봐 볼넷 종료를 만들고, 네 문항의 `예` 버튼·메모·결과 저장·다음 플레이어를 클릭했다. 새 렌더에서도 저장 건수 1/3이 유지되고 날짜 기반 JSON 파일 다운로드가 호출되는 것을 확인했다.
- 확인하지 못한 것: 브라우저 런타임 복구 절차와 사용 가능 유형 조회 뒤에도 목록이 비어 있어 실제 픽셀·레이아웃과 스크린샷 QA를 수행하지 못했다.
