## 계측 재검산

정적 범위 src/duel/*.css, 위 기준 SHA에서 재현:

| 항목 | 값 |
| --- | ---: |
| CSS 파일/개행 | 21 / 5258 |
| !important 등장/포함 줄 | 2266 / 1024 |
| 색 리터럴 등장/중복 제거 문자열 | 2500 / 2106 |
| 고정 px font-size <11 / <12 | 433 / 493 |

원 브라우저 보고의 186개 분포에는 11px 14개가 포함된다.
따라서 **<12px 186/211(88.2%), <11px 172/211(81.5%)**로 정정했다.
이는 원 보고의 내부 산술 검산이며 이번에 브라우저에서 새로 수집한 값이 아니다.

원 좌표의 HP 전체~보드 전체=717px, 보드 전체~손패 전체=740px는 844px보다 작다.
따라서 '어느 스크롤 위치에서도 각각 동시에 못 본다'는 결론은 성립하지 않는다.
**HP 전체~손패 전체=1093px**로 전체 조작 묶음의 공간 문제는 남는다.
고정 헤더·버튼·클리핑·safe area를 넣은 실제 상태 검사가 필요하다.

!important의 많음은 유지보수 위험이지만 특정 겹침 버그의 원인 증명은 아니다.
5개 색 조합 중 1개가 실패한 자료로 대비 문제를 배제할 수도 없다.
원 보고에는 seed/저장 fixture/수집 스크립트가 없으므로 P0에서 보완하도록 했다.

## 시안 판단

카드 형태 시트와 A/B/C 비교 이미지를 확인했다.
**C의 정면 보드·큰 손패 + B의 정보 위계**를 권고하되,
판정에서는 기존 경기장/배우 연출을 유지한다. 정면 보드는 비교를 돕지만 이해도는 아직 미검증이다.

불투명 카드로 판을 덮는 안은 읽기 분포·순번·중복 편집을 가릴 수 있다.
반투명 셀·기준 존 토큰·순서 링크로 바꿔 프로토타입에서 확인한다.
기존 PNG는 수정 전 설계 이력으로 남겼으며 입구 문서에서 이를 명확히 표시했다.
수정된 인터랙티브 시안이나 새로운 아트 이미지를 만들었다고 주장하지 않는다.
