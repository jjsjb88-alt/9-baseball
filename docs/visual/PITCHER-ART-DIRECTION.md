# 투수 캐릭터 아트 기준

기준일: 2026-09-24. 사용자가 요청한 방향: “투수는 씹덕스타일의 엄청 이쁜 2d 도트캐릭터들이 다양하게 나오는걸로 기준으로 삼자”.

## 2026-09-24 참고 이미지 반영 — 현행 얼굴 표현 기준 (v2)

사용자가 제공한 참고 이미지에서 핵심은 큰 눈의 섬세한 표정, 작은 입과 코, 반짝이는 머리카락의 넓은 하이라이트, 선명한 단계 명암, 고밀도 애니메이션 도트 표현이다. 이 기준이 기존 v1 시안보다 우선한다. 기존 v1 원본은 보존하되, 앞으로 전신/애니메이션 제작 시 얼굴과 명암 표현은 v2 방향으로 발전시킨다.

- **눈과 얼굴**: 넓은 홍채, 또렷한 윗속눈썹, 작은 광점, 간결한 코와 입. 입술을 사실적으로 묘사하거나 얼굴을 사진처럼 매끈하게 칠하지 않는다. 캐릭터별 눈매와 표정 차이를 유지한다.
- **헤어와 명암**: 머리카락의 큰 흐름과 광택 띠를 의도적인 픽셀 덩어리로 설계한다. 픽셀 경계와 셀 애니메이션식 명암 면을 선명하게 유지한다.
- **초상/전신 분리**: 얼굴이 크게 보이는 초상에서 매력을 먼저 확인한다. 전신 에셋에서도 같은 얼굴과 헤어 정체성을 유지하며, 투구 동작과 작은 화면의 가독성을 함께 검증한다.
- **독자 디자인**: 참고할 것은 일반적인 표현 기법이다. 특정 캐릭터의 얼굴 정체성, 특징적인 헤어·색·복장·장식 조합, 상징과 설정을 그대로 가져오거나 단순히 야구복만 입힌 형태로 만들지 않는다.
- **다양성**: 얼굴, 눈매, 헤어 실루엣, 피부색, 유니폼 배색과 동작을 함께 설계한다. 실제 로스터의 구종·성격·체형은 각각의 캐릭터 설계에 따라 확장한다.

새 초상 시안과 정확한 프롬프트: [pitcher-anime-v2](../../assets/pitcher-anime-v2/README.md). 청록/산호 눈, 갈색 땋은 머리/호박 눈, 장밋빛 단발/민트 눈의 세 인물이며, 고유 외형 조합을 새로 명세했다. 이 단계는 디자인 시안이며 사용자 최종 승인이나 게임 적용 완료를 뜻하지 않는다.

### 참고와 권리

참고 원본은 프로젝트 에셋으로 재배포하지 않는다. 생성 시 일반적인 도트 표현만 참고하고 독자적인 캐릭터 디자인을 명시한다. 특정 디자인의 저작권 무침해를 보증하는 검토는 수행하지 않았다. 일반적인 아이디어와 구체적인 시각 표현은 구분되므로, 단순한 색 변경을 안전성의 근거로 삼지 않는다. 관련 일반 안내: [미국 저작권청의 시각미술·캐릭터 안내](https://copyright.gov/comp3/chap900/ch900-visual-art.pdf).

이번 수정도 PNG/문서만 추가·수정하며 실행 코드·CSS·저장·입력·밸런스·배포에는 영향을 주지 않는다. 아래 9개 축의 영향도 판단은 유지한다.


## 캐릭터 방향

투수 로스터는 매력적인 애니메이션 캐릭터를 정교한 2D 픽셀아트로 표현한다. 이번 1차 로스터는 성인 여성 캐릭터 3종으로 구체화했다. 얼굴의 매력과 표정, 서로 다른 인상, 야구 선수로서의 실루엣을 함께 설계한다.

- 캐릭터마다 얼굴, 눈매, 피부색, 헤어 실루엣, 체형, 표정, 유니폼, 글러브, 투구 자세를 구분한다. 단순한 머리색 교체로 로스터를 늘리지 않는다.
- 큰 색면과 의도적인 도트 덩어리, 단계적인 명암, 또렷한 윤곽을 우선한다. 축소 화면에서 뭉개지는 미세 장식은 줄인다.
- 야구 모자, 글러브, 스파이크, 축발과 체중 이동이 읽혀야 한다. 아름다운 얼굴과 실제 투수 동작을 함께 만족시킨다.
- 기본 방향은 화면 오른쪽에서 왼쪽 타자를 향한다. 캐릭터별 키포즈, 릴리스 높이, 투구 리듬에 개성을 준다.
- 경기장의 청록색 저녁빛과 어울리는 색온도를 사용한다. 캐릭터 PNG와 바닥 그림자·투구 효과는 별도로 관리한다.
- 원본은 배경이 투명한 PNG로 보관한다. 애니메이션 작업 시 같은 캐릭터의 얼굴·체형·유니폼을 고정하고 set → windup → release → follow-through → settle 순서를 설계한다.

## 런타임 적용 시 검토

PNG 원본 생성과 런타임 적용은 별도 단계다. 이 원본은 공통 논리 픽셀 격자와 팔레트가 기계적으로 보장된 아틀라스가 아니다. 실제 적용 시 프로젝트 크기의 픽셀 격자·팔레트·발 기준점·화면상 크기를 정하고, 필요한 포즈를 추가한다. 보간 없는 픽셀 렌더링, 투명 경계, 작은 화면의 얼굴·손·글러브 가독성을 확인한다. 카메라/VFX와 함께 모바일 세로, 모바일 가로, PC에서 검증한 뒤 통합한다.

## 생성과 검증

내장 image_gen 사용. 생성 원본의 알파를 유지하여 복사했다. 에이스는 머리 윗부분 여백을 보완했고, 마무리는 배경 제거 편집을 거쳤다. 마무리 PNG는 청록색 바탕 위의 축소 미리보기에서 배경 광채가 남지 않음을 확인했다. 세 캐릭터의 PNG 메타데이터와 가장자리 검사는 assets/pitcher-anime-v1/qa.json에 저장한다. 전체 생성/수정 프롬프트는 assets/pitcher-anime-v1/PROMPTS.md에 기록한다.
