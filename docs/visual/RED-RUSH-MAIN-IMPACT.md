# 레드 러시 투수 에셋: 최신 main 통합 전 영향도 분석

현재 main의 정규 투수는 v4 60프레임 남성 스프라이트를 사용한다. 새 레드 러시는 독자적인 성인 여성 SD 디자인, 120개의 고유 투구 프레임, 전신 선택 초상화를 가진 첫 정규전 상대다. 다른 상대와 기존 저장 데이터에는 현재 렌더링을 유지한다.

| 축 | 판단 | 대응 |
| --- | --- | --- |
| UI / 레이아웃 | 영향 있음 | 첫 정규전의 투수 액터와 경로 미리보기만 교체한다. 기존 액터 박스·그림자·이름표는 유지한다. |
| 입력 / 제스처 | 영향 없음 | 새 클릭/드래그 입력을 추가하지 않는다. |
| 게임 로직 / 밸런스 | 확인 필요 | 첫 정규전 상대의 표시 이름과 선택적 artId만 변경한다. HP, 확률, 투구/피해 계산은 그대로 둔다. |
| 저장 / 불러오기 | 영향 있음 | artId가 없는 과거 런은 기존 v4 투수로 보이게 한다. 새 런의 artId만 저장된다. |
| 모바일 뷰포트 | 영향 있음 | 기존 액터 박스 안에 256px 셀을 그려 세로·가로에서 화면 침범을 확인한다. |
| 스크롤 / 오버플로 | 영향 없음 | 전역 크기·overflow를 바꾸지 않고 경로 초상화는 기존 미리보기 안에 넣는다. |
| 기존 사용자 플로우 | 확인 필요 | 타이틀→첫 경로→전투→투구/결과, 다른 투수 전투, 저장 후 이어하기를 확인한다. |
| 테스트 / 회귀 | 영향 있음 | 120개 프레임, 방향/아틀라스, 첫 상대 ID, 투구 타임라인, 기존 v4 분기를 검증한다. |
| 빌드 / 배포 | 영향 있음 | 런타임은 아틀라스 한 장과 초상화 한 장을 import한다. 전체 테스트, 스모크, 빌드, 배포를 확인한다. |

기존 v4는 다른 상대의 폴백으로 남긴다. 새로운 이미지는 참고 자료의 일반적인 SD/픽셀 표현만 참고한 원본 디자인이며 법적 무침해를 보증하지 않는다.

실기기 검증에서 발견한 기존 V10 이어하기 오류도 함께 수정한다. 지켜보기 결과의 imZone: null을 저장 검증에서 허용하고, 저장/복원 회귀 테스트로 고정한다.
