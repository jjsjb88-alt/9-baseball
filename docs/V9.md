# V9.2 — 카드로 만들고, 상대를 고르고, 판정을 터뜨리는 런\n\n## 제품 정의\n\nV8.10의 세 완성형 덱은 실패한 시작 덱이 아니다. 실제 플레이에서 코어 야구가 재미있다는 피드백을 얻기 위해 만든 **완성형 체험 / 튜토리얼 아키타입**이다.\n\nV9의 메인 게임은 그 재미에 도달하는 과정을 플레이어가 직접 만든다.\n\n> 약한 공통 덱으로 시작한다 → 야구 승부를 이긴다 → 세 카드 중 하나를 고른다 → 다음 경기에서 덱의 플레이가 달라진다.\n\n`몸쪽 장타 / 바깥 연결 / 끈질긴 컨택`은 메인 런의 출발점이 아니라, 플레이어가 도달하거나 섞어 만들 수 있는 방향의 예시다.\n\n## 현재 구현 계약\n\n### MAIN RUN · 무명 타선\n\n- 9장 공통 스타터.\n- `맞혀놓기 ×4 / 밀어치기 ×2 / 타이밍 맞추기 / 작전 확인 / 릴리스 간파`.\n- 완성형 핵심 카드 `당겨 넘기기 / 주자 연결 / 커트 스윙 / 희생 번트 / 히트앤드런 / 갭 공략`은 시작 덱에 넣지 않는다.\n- `맞혀놓기`는 1존 커버의 약한 스타터 카드다. 좋은 카드가 생겼을 때 덱이 바뀌었다는 체감을 만들기 위한 부품이다.\n\n### 경기 보상\n\n경기 승리의 기본 보상은 **카드 3장 중 1장 또는 건너뛰기**다. 강화·제거·유물은 전투 카드 보상과 경쟁시키지 않는다.\n\n1. 첫 보상: `당겨 넘기기 / 주자 연결 / 커트 스윙`\n2. 두 번째: `릴리스 간파 / 히트앤드런 사인 / 갭 공략`\n3. 세 번째: `코스 조정 / 희생 번트 / 호흡 고르기`\n\n현재 4경기 / 3카드 보상이다. 카드 선택 자체가 메인 런의 1차 성장이다. V8의 `기다림 / 연결 / 행운` 강제 성장 선택은 메인 런에서 사용하지 않는다.

### V9.1 · 경기 사이 시설

카드 보상과 팀 정비를 같은 화면에 섞지 않는다. 카드 선택을 끝내면 다음 경기 전 **두 시설 중 하나만** 들를 수 있다.

1. 1→2경기: `타격 훈련` vs `스카우팅`
   - 타격 훈련: 카드 1장 강화
   - 스카우팅: 다음 한 경기 동안 읽기 등급 +1
2. 2→3경기: `라커룸 정리` vs `장비실`
   - 라커룸 정리: 카드 1장 제거
   - 장비실: 유물 1개 선택
3. 3→4경기: `타격 훈련` vs `장비실`

스카우팅은 숨은 실제 공을 공개하지 않는다. 공개 정보의 해상도만 한 단계 올리고, 다음 경기 이후 자동으로 사라진다. 시설 기록은 카드 보상과 함께 런 히스토리에 남는다.

### V9.2 · 상대 브랜칭

메인 런은 매 경기 시작 전에 **안정 루트와 고위험 루트 중 상대를 직접 고른다**.

- 고위험 루트는 목표 득점이 +1 올라가고 투수 구위·변화·제구가 실제로 상승한다.
- 앞선 3경기의 고위험 상대를 꺾으면 다음 카드 드래프트가 3장 → 4장으로 넓어진다.
- 최종전 라이벌 에이스는 추가 카드 대신 격파 기록 자체가 런 결과에 남는다.
- 상대 선택, 승리 기록, 보너스 후보는 저장/복원된다.
- 경로 선택은 지도 장식이 아니라 **다음 타석의 난도와 다음 덱의 선택지를 동시에 바꾸는 야구 결정**이어야 한다.

### MASTER PRESENTATION · 판정은 보상이다

이 게임은 생각하는 시간이 긴 게임이므로 판정 순간이 약하면 전체 플레이가 약해진다. 연출은 장식이 아니라 **읽고 판단한 시간을 돌려주는 핵심 보상 시스템**이다.

- 릴리스 간파: 스캔 라인과 존 점멸로 **READ / 읽었다**.
- 코스 적중: 순간 정지·충격 링·실제 존 잠금으로 **READ CONFIRMED / 맞혔다**.
- 2루타: 별도 장타 콜 **GAP SHOT / 갈랐다**.
- 홈런: 가장 큰 화면 버스트·카메라 충격·전용 비행·전용 음향으로 **PERFECT CONTACT / 넘겼다**.
- 헛스윙: 공이 배트를 통과하고 실제 존과 커버 실패를 동시에 보여주는 **MISS / 빗나갔다**.
- 파울: 튕김 궤적과 생존 판정 **STAY ALIVE / 살아남았다**.
- 볼·볼넷: 차가운 색조의 **TAKE / 골랐다·참아냈다**.
- 루킹 스트라이크·삼진: 정적과 프리즈를 이용한 **CALLED STRIKE / 지켜봤다·굳었다**.
- 희생·아웃도 동일한 공통 플래시가 아니라 독립된 판정 언어를 가진다.
- 준비 카드도 READ / LOCK / EXPAND / SIGN / RESET / OPTIONS로 분리한다.
- 판정 텍스트, 시각 효과, 오디오 큐는 src/duel/presentation.js를 중심으로 같은 의미를 공유한다.
- prefers-reduced-motion에서는 연출을 60ms 안에 정리하고 영구 결과 패널로 정보를 보존한다.
- 판정은 `windup → impact → slowmo(선택) → release → settle` 타임라인을 가진다. 모든 결과에 슬로모션을 쓰지 않는다.
- 선택적 슬로모션: 한 칸 차이 헛스윙, 빗맞은 안타, 행운의 안타, 정확 적중, 홈런처럼 **기다림이 감정을 키우는 순간에만** 사용한다.
- 안타는 정확 적중 / 일반 정타 / 빗맞은 땅볼 안타 / 행운의 바가지 안타 / 2루타 / 홈런 / 만루홈런으로 분리한다.
- 헛스윙은 한 칸 차이 / 유인구 추격 / 완전 오독으로 분리하고, 삼진 상황에서도 이 원인을 유지한다.
- 2스트라이크 파울, 밀어내기 볼넷, 득점 희생처럼 같은 원시 결과도 상황에 따라 다른 판정 장면이 된다.
- 시각: 히트스톱, 전체 화면 셰이크, 카메라 줌, 충격파, 스파크, 속도선, 실제 존/커버 비교, 타구 궤적, 전광판/베이스 펄스를 조합한다.
- 음향: Web Audio로 타격 저역, 노이즈 임팩트, 공기음, 스테레오 이동, 판정 톤, 홈런 관중 스웰을 레이어한다.
- 촉각: 지원 모바일에서는 판정 강도별 `navigator.vibrate` 패턴을 사용한다. 미지원/실패 시 게임 진행에 영향이 없다.\n\n### 완성형 체험\n\n기존 세 아키타입은 삭제하지 않는다: 몸쪽 장타 / 바깥 연결 / 끈질긴 컨택.\n메뉴에서 **완성형 체험**으로 명시한다. 이 모드에서는 기존 성장·강화·제거·유물 계약을 유지한다.\n\n## 플레이 피드백 반영\n\n곽윤 플레이 피드백: "그 안타인지 막 그런거 결과가 좀 더 크게 직관적으로 뜨면 좋을 것 같아요"\n\nV9 브랜치에서는 안타 / 헛스윙 / 파울 / 볼 / 스트라이크 / 아웃 결과를 작은 로그가 아니라 타석 결과 패널의 가장 큰 정보로 표시한다. 색만이 아니라 큰 결과 단어와 결과명으로 구분한다.\n\n## 저장\n\n- V9 저장 키: `9zone-deckbuilder-v9`\n- 배포된 V8 저장 `9zone-read-v8` 및 v5/v6/v7 키는 지우거나 덮어쓰지 않는다.\n- V9 저장은 version 9로 별도 검증한다.\n\n## 검증\n\n브랜치: `codex/v9-deckbuilder`\n\n- Vitest: **124 / 124 통과**\n- V9.2 UI: 메인 런, 상대 2택1, 카드 드래프트, 시설 2택1, 큰 판정 연출 회귀\n- V9.2 엔진: 9장 스타터, 상대 경로 난도/보너스, 카드 추가/건너뛰기, 시설 강화·제거·장비·임시 스카우팅, 저장 복원\n- V9.2 30시드 full-run 스모크: **7/30 완주**, 평균 최종 덱 10.5장. 상대 브랜치를 실제로 고르며 저장/종료를 검증\n- 모든 전이 저장/복원 및 1000행동 종료 가드\n- 기존 zone/growth/deck-relic 리포트 통과\n- 프로덕션 Vite 빌드 통과\n\n자동 정책 수치는 **인간 재미나 밸런스의 증명이 아니다**. 첫 스타터가 처음에는 10/10 자동 완주였기 때문에 약한 1존 스타터 카드로 재설계했고, 30시드 완주가 30%로 내려온 것은 덱 성장이 실제로 필요해졌는지 보는 회귀 신호일 뿐이다.\n\n## 다음 단계 — V9.2\n\n덱빌딩이 확인되기 전까지 코어 야구를 다시 갈아엎지 않는다.\n\n- 경기: 카드 3장 중 1장\n- 타격 훈련: 카드 강화\n- 라커룸 / 방출: 카드 제거\n- 장비실: 유물\n- 스카우팅: 다음 투수 정보 또는 경로 정보\n- 강팀 / 라이벌: 구현 완료. 다음은 실제 사람 플레이에서 위험 대비 보상이 체감되는지 검증
