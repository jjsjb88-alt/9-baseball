초기 감사 기준: 2026-09-28. 현재 상태는 GitHub `jjsjb88-alt/9-baseball`의 `main`과 대조한다. **이 파일의 A01–A09만으로 10개 목업은 완성되지 않는다.** 2026-09-28에 **C항목(V16 보상 카드 일러스트 C01–C11, C101~)**이 추가됐다. 전체 화면별 기존/부족/검수 목록은 [`FULL_MOCKUP_ASSET_AUDIT_2026-09-28.md`](FULL_MOCKUP_ASSET_AUDIT_2026-09-28.md)에 있다. 새 채팅은 두 파일과 `docs/art/MOCKUP_FIDELITY_PLAN_2026-09-28.md`, `docs/art/working/RED_RUSH_REUSE_GAP_MATRIX_2026-09-28.md`를 읽고 **현재 GitHub 파일과 새 업로드를 다시 확인**한 뒤 확정·조건부·기존 검수 항목을 모두 보여준다. 코드 연결과 10화면 품질 통과 여부는 별도다.

## 새 채팅에서 쓸 문장

> `jjsjb88-alt/9-baseball`의 `main` 브랜치에 있는 `docs/art/FULL_MOCKUP_ASSET_AUDIT_2026-09-28.md`, `docs/art/PHONE_ASSET_QUEUE.md`, `docs/art/V16-CARD-ART-QUEUE.md`를 읽고 현재 GitHub와 대조해 **10개 목업 전체의 기존/확정 부족/조건부 에셋과 C항목(V16 카드 일러스트)**을 보여줘. 이미 제작된 파일과 연결 상태를 다시 확인하고, 첫 번째 확정 미완료 항목만 휴대폰에서 만들 수 있도록 구체적인 이미지 제작 프롬프트를 줘. 내가 PNG를 한 장씩 올리면 원본과 목업을 비교해 검수하고, 합격한 파일만 새 버전 폴더와 체크리스트에 반영해. 레드 러시는 여성형을 유지해.

## 진행 규칙

1. **한 번에 한 번호**만 제작·업로드한다. 새 채팅은 전체 목록을 보여주되, 상세 제작 프롬프트는 맨 앞 미완료 번호 하나만 제시한다.
2. 휴대폰에서 만든 이미지는 **원본 PNG 파일로 첨부**한다. 화면 캡처나 여러 에셋을 합친 콜라주는 최종 원본으로 받지 않는다. 투명 컷아웃은 진짜 알파 채널을 확인한다.
3. 이미지 안에 게임 글자, 로고, 버튼, HP, 숫자를 굽지 않는다. UI 배치는 별도 작업이다. 파일 하나에는 아래에 지정한 인물·배경·VFX 중 **한 종류만** 넣는다.
4. 인물은 얼굴·손·장비·발이 모두 보여야 하고, 100px 높이에서 실루엣을 읽을 수 있어야 한다. 기존 `#9` 타자와 **여성형** 레드 러시의 외형을 바꾸지 않는다.
5. 검수 순서: 업로드 → 기존 아트/목업과 같은 크기 비교 → 해부학·알파·모바일 크롭 확인 → 합격 시 버전 폴더 저장과 매니페스트 갱신 → 이 문서의 `[ ]`를 `[x]`로 바꾸고 커밋·푸시. **파일이 있다는 이유만으로 완료 표시하지 않는다.**
6. 기본 모바일 확인 크기는 세로 `412×743`, 가로 `844×390`이다. 인물 원본은 긴 변 **최소 1024px**, 배경은 긴 변 **최소 1536px**을 권장한다. 휴대폰 도구가 정확한 픽셀 수를 지원하지 않으면 가장 큰 원본을 올린다.

## C · V16 보상 카드 일러스트 — 새 카드 135장 (2026-09-28 추가)

보상 카드가 16장에서 **151장**(신규 135장, 11개 덱 콘셉트)으로 늘었다. 코드와 규칙은 `claude/integrate-ag-v15` 브랜치에 있다(`src/duel/cards-v16.js`). 새 카드는 전용 그림이 없어 콘셉트마다 V15 카드 원화 한 장을 **빌려 쓰는 중**이다. 카드 한 장마다의 목록·효과·그림 방향은 [`V16-CARD-ART-QUEUE.md`](V16-CARD-ART-QUEUE.md)에 있다.

**공통 규격 (C 전체):** 기존 `assets/cards-v15/*.png`와 **같은 화풍·밀도**(고밀도 2D 픽셀 아트, 석양 야구장 조명), **세로 2:3 · 1024×1536 이상 · 불투명 PNG**, 글자·숫자·로고·카드 테두리 없음. 게임은 이 그림을 카드 위쪽 창에 `cover`로 자르므로 **주제를 가운데 60% 안에** 둔다. 100px 폭으로 줄여도 무엇을 하는 장면인지 읽혀야 한다. 타자가 나오면 기존 #9(남색 헬멧·크림 유니폼·금색 줄), 투수가 나오면 기존 여성형 레드 러시 외형을 유지한다.

**연결 방법:** (자동 연결 코드는 `claude/integrate-ag-v15`에 있고, 이 브랜치에 올린 파일은 통합 때 함께 합쳐진다.) 합격한 파일을 `assets/cards-v15/`에 아래 파일명으로 넣기만 하면 게임이 자동으로 그 콘셉트 카드 전체에 쓴다(`src/duel/card-art.js`). 카드별 전용 그림(C101~)도 `card-<카드키>.png`로 넣기만 하면 된다(매핑 수정 불필요).

## A01을 바로 만들 때 쓸 첫 프롬프트

> 기존 9ZONE HOMEBOUND의 홈런 장면과 목업을 참고해, **타자 #9 한 명만** 고해상도 픽셀 아트 투명 컷아웃으로 그려줘. 휴대폰 가로 화면에서 왼쪽 전경에 크게 놓일 뒷모습/어깨너머 시점이다. 남색 헬멧, 흰색 야구 유니폼과 등번호 9, 양손으로 쥔 방망이, 스윙을 마친 체중 이동이 자연스럽게 보여야 한다. 얼굴·체형·유니폼은 기존 게임의 #9 타자와 일치시켜줘. 머리·배트·손·발을 모두 캔버스 안에 넣고 가장자리 여백을 남겨줘. **진짜 투명 PNG**, 배경·관중·공·궤적·글자·로고·UI·다른 인물 없음. 100px 축소에서도 타자 실루엣과 배트 방향이 읽히게.

업로드 시에는 A01 원본 PNG 한 장과, 사용한 생성 도구가 있다면 그 이름만 알려준다. 새 채팅은 업로드된 이미지를 검수한 뒤 다음 번호를 안내한다.
