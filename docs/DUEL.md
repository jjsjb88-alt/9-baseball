# DUGOUT / ACT 0 — 최신 설계 및 인수인계

2026-09-09. 현행 진입점: `src/main.jsx → src/duel/App.jsx`.

## 핵심 방향

사용자가 원하는 것은 슬더스형 로그라이크 덱빌딩과 고품질 2D 도트 그래픽이다. 이전 LAST LIGHT는 여전히 코스 찍기에 머물렀다. 이번 버전은 **공개된 의도를 여러 카드의 순서와 조합으로 해결하는 전투**다. 코스 선택, PUBLIC/TRUE INTENT의 숨은 차이, 접촉 확률, 숙련존을 사용하지 않는다. 아래 역사 문서를 이유로 이전 구조를 되살리지 않는다.

- 턴당 행동력 3, 손패 5장(최대 10장), 여러 카드 사용 후 턴 종료. 공격은 확정 적중. 무작위는 덱 섞기에만 있다.
- ROOKIE 1명과 전투 4회, 중간 카드 보상 3회, 카드 12종. 시작 덱 10장, 최종 덱 10–13장.
- 평정심=플레이어 HP 50. 제구=상대 HP 34/44/54/70. 실제 야구 이닝/득점이 아닌 심리전의 전투 추상화다.
- 승리 시 HP 5 회복, 보상 3개 중 1장 또는 건너뛰어 추가 HP 4 회복. HP 0이면 패배, 마지막 전투를 이기면 클리어.
- 손패는 턴 종료 시 버리고 새로 5장. 뽑을 카드가 없으면 버린 카드를 섞는다. 소멸 카드는 다음 전투에 돌아온다. 뽑을 카드 목록은 순서를 숨긴다.
- 노림은 중첩당 다음 공격의 첫 타격 +3, 공격 시 전부 소비. 노림/유리한 카운트는 다음 턴에도 유지. 방어는 턴 시작에 초기화. 침착함은 이후 매 턴 방어 3.
- 투수의 의도는 공개된 고정 패턴이다. 현재 플레이어 선택을 몰래 보고 바뀌지 않는다. 직구 유도 카드만 현재 의도를 명시적으로 바꾼다.
- 첫 보상에서 직구 유도를 고르면 ‘볼 골라내기 → 직구 유도 → 풀스윙’ 연계 가능. 같은 손패에 모으는 덱 순환이 필요하다.
- 변화구에 풀스윙만 사용하면 피해 12. 위 3장 연계는 행동력 3으로 방어 5, 상대 공격 -2, 피해 25. 상대 방어/잔여 HP에 따라 실제 피해는 줄어든다.

## 변경 위치

- cards.js: 카드/스테이지/보상/용어.
- engine.js: 순수 판정 엔진, 상태 전이, 저장 검증. 미리보기와 테스트도 playCard를 호출하며 피해식을 복제하지 않는다.
- App.jsx / duel.css: 화면, ref 기반 즉시 입력 잠금, 미리보기, 저장 및 연출. 상태를 먼저 저장하고 포즈/효과를 재생한다.
- audio.js: 사용자 ON 후 합성 효과음. 소리 실패가 판정을 막지 않는다.
- policy.js: 동일 엔진을 사용하는 bounded QA 탐색기.
- tests/duel-engine.test.js / duel-ui.test.jsx: 연계, 확정 피해, 저장, 카드 보존, 중복 입력, React 클릭 완주.
- assets/duel/: 새 도트 구장과 캐릭터 각 3포즈. README에 원본 생성 프롬프트 및 크기 기록.

새 저장 키는 `9zone-duel-v1`. 이전 앱/소스/자산/저장은 보존하지만 현행 앱이 import하지 않는다. 이후에는 src/duel에 통합하며 또 다른 기본 앱을 만들지 않는다.

## 실행과 검사

`npm install` → `npm run dev`. 검사: `npm test`, `npm run build`.
패키지 shim이 실패하면 `node node_modules/vitest/vitest.mjs run`, `node node_modules/vite/bin/vite.js build`로 직접 실행한다.

- 전체 51개 테스트(신규 10개 + 기존 41개) 통과 및 빌드 성공.
- 시드 42로 실제 React 클릭을 통해 4전투/3보상/클리어, 저장 복원 검증.
- 브라우저에서 방어 5 후 공격 6의 실제 피해 1, 카드 사용, 1280px/390px 배치 확인.
- 첫 카드 잘림, 체력바 얼굴 겹침, 불균등 생성 시트의 인접 포즈 노출을 수정했다.
- QA 탐색기 시드 1–100: 100완주, 평균 턴 종료 11.24회, 사용 카드 38.08장. 이 탐색기는 **미래 드로까지 실제 엔진으로 계산**하므로 공정한 인간 모사나 난이도/재미 근거가 아니다. 완주 경로의 기능 검사에 한정한다.
- 인간 플레이 시간/재미, 모든 브라우저 조합, 효과음 청취, 완전한 스크린리더 탐색은 미검증.
