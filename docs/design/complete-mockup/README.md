## 단일 시각적 목표

고밀도 2D 픽셀 아트 + 석양의 야구장 + 타자/투수의 완성도 높은 인체 실루엣 + 전광판/9ZONE 보드 + 일관된 카드 프레임 + 강렬한 판정 연출. SVG 블록형 캐릭터나 저밀도 임시 아트로 대체하지 않는다.

### 전투 화면 우선순위

1. **세로 전투 레이아웃:** 상단 로고/이닝/BSO/덱/버린 카드/설정, 중앙 석양 야구장과 타자/투수, 투수 HP, 전면 3×3 존 보드, 코치 대사, 하단 손패 4장과 휘두른다/지켜본다 버튼.
2. **9ZONE 경로:** 번호 1→2→3의 연결을 밝은 황금색 선과 존별 강조로 명확히 표시. 실제 게임 엔진의 유효 경로와 일치해야 한다.
3. **카드 선택:** 비용·일러스트·태그·설명을 유지하면서 선택 카드에 명확한 빛/테두리 효과. 단순 이미지 오버레이가 아닌 실제 인터랙션.
4. **연출:** 투구→타자 스윙→컨택→홈런→상대 격파→보상 선택. 키포즈 연속성, 얼굴/배트 파손 방지, 실제 모바일 재생 검증.
5. **전체 게임:** 종합 목업의 타이틀, 지도 경로, 카드 보상, 덱 관리, 선수 도감, 엔딩을 공통 디자인 시스템으로 구성.

## 구현과 검수의 구분

- 원본 목업은 **목표 레퍼런스**이지 이미 완성된 게임 에셋/구현 코드가 아니다.
- 목업을 게임에 바로 배경 이미지로 깔아 버튼만 덧대는 방식은 금지. 개별 캐릭터·구장·UI·카드·VFX 에셋으로 분리해 실제 게임 상태에 연동해야 한다.
- 원본 이미지의 문구·카드 수치·HP는 시각 예시이며 실제 게임 로직은 기존 계약과 비교 검증 후 반영한다.
- 먼저 실제 390×844 화면에서 전투를 구현/캡처해 원본과 직접 비교한다. 이어 844×390, 1440×900에서 검수한다.
- main 병합/배포는 사용자 눈 검수 전까지 금지. 기존 작업 세션과 충돌하지 않도록 디자인 문서/에셋 경로를 별도 관리한다.
