## 검수할 때 특히 봐 달라는 것

1. **카드가 칸을 물리적으로 덮는다**는 전제(`card-shape-language.png` 하단 보드).
   이게 부정되면 기획의 절반이 재설계다.
2. **390px에서 십자 카드가 판의 절반을 가린다.** 가독성이 버티는가. 실물 프로토타입 전이라 미검증이다.
3. 3방향 중 **무엇을 고를지**. 아트 일정까지 결정된다.
4. 카드 이름 16종(2~8자)을 **재명명할지**. 제품 정체성이라 임의로 정하지 않았다.

## 이 자료가 증명하지 못하는 것

- **모션.** 기획의 절반이 움직임인데 시안은 전부 정지 1장이다.
- **아트 품질.** 타자/투수 픽셀아트는 어느 시안으로도 해결되지 않는다.
  `HANDOFF.md`의 VISUAL REBOOT 기준은 그대로 유효하다.
- **사람.** 표본은 테스터 1명이다. 별·등급·권고는 설계 판단이지 측정값이 아니다.
  측정된 것은 위 실측표뿐이다.
