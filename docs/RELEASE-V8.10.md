# V8.10 릴리스 기록

## 변경과 의도

- v8 덱 설계 기반을 통합한다. src/duel 엔진/화면을 수정했으며 별도 게임을 만들지 않았다.
- 유물 미리보기/확정이 서로 다른 객체를 만들던 버그를 제거했다.
- 번트/커트 강화는 사용되지 않는 파워 수치 대신 실제 판정의 성공·생존 확률을 바꾼다.
- 강화 관찰의 행+열 정보가 미리보기에도 들어간다. 어떤 관찰도 선택으로 투구를 바꾸지 않는다.
- 카드 수치로 읽기 등급을 우회하지 못하게 공개 셀의 하한/상한을 합산하고 여집합으로 좁힌다.
  같은 공개 범주인 서로 다른 실제 분포는 같은 카드 구간을 보여야 한다.
- 타석 전 9존 리포트, 보상 전 내 덱, 다음 상대, 선택의 변화, 지도에 남는 보상 이력.
- 연결 성장에 필요한 번트를 모든 시작 덱에서 선택해 구할 수 있다. 번트를 강제하지 않는다.
- 카드 효과는 숨기지 않는다. 데스크톱/모바일 2열 손패에 커버 모양, 비용, 효과가 표시된다.
  상세 스탯과 진단만 접으며, 실행 버튼은 실제 카드와 비용을 말한다.
- 지켜보기는 비소모 선택 후 별도 실행. 한 공/타석 전환 가드는 유지.
- 기존 PNG·음향 유지. 땅볼/바가지/홈런 공 궤적 구별, reduced-motion 대응.
  120개의 고유 도트 프레임을 새로 만든 작업은 아니다.

## 검사

- 103개 단위/React 회귀 검사. 기존 90개 + 신규 13개.
- 신규 React: 추가·제거·강화·유물·건너뛰기 실제 버튼 확정/중복 방지/복원, 지켜보기 선택 비소모.
- 신규 엔진: 번트/커트 강화 실효, 강화 관찰 일치, 낮은 등급 단서 활용과 수치 비누출,
  공개 구간 안 실제 확률 포함, 45개 전체 런 보상/저장 회귀.
- deck-report 5: 3시작 덱 × (baseline+12강화+3유물) × 5시드 = 240런.
  매 행동 저장 복원과 1000행동 종료 가드. 획득할 수 없거나 첫 승리 전에 진 런의 acquired=0은
  강화 가치 0이라는 뜻이 아니다. 첫 합법 보상에서 한 효과만 획득하고 나머지는 건너뛰는 조건이다.
- 정책에는 숨은 pending/미래 드로를 읽는 권한을 주지 않는다.
- 브라우저: 시드1 정상 클릭으로 첫 경기 2득점 승리, 행운+망원경 보상 확정, 다음 경기 리포트 확인.
  모바일 390×844에서 보상 선택·확정, 가로 넘침 없음. 데스크톱 손패/커버/공개 단서 이미지 직접 확인.
- 프로덕션 빌드 /9-baseball/ 경로 확인. 배포 확정은 해당 main 커밋의 Actions 성공과 공개 화면 확인으로 기록.

## 남아 있는 것

- 사람 피드백은 이미 존재한다. “퍼즐 같다”, “한 공 여러 공격은 야구가 아니다”,
  “적중했는데 안타가 안 나오면 불합리하다”, “카드 비교를 숨기면 덱빌딩을 못 한다”가 설계 근거다.
- 별도 다인 정량 플레이테스트, 실제 30분, 세 성장의 균형, 재도전 욕구는 아직 입증하지 않았다.
- 4경기·3보상이다. 30분을 맞추려고 자동으로 경기 수를 늘리지 않았다.
- 읽기 등급의 정보 획득이 전략인지 필수 편의 구매인지 추가 사용자 검증이 필요하다.
- 아트는 기존 3포즈다. 타구 궤적 개선은 최종 아트/120프레임 완성을 뜻하지 않는다.
- 원본 dirty main의 level/deckEdits 실험을 plus/rewards v8과 다시 섞지 않는다.
- 라이선스는 임의 선택하지 않았다. 기존 자율 루프는 시작하지 않았다.
