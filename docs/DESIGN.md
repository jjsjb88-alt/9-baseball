# DESIGN

## 최우선 v6 성장 계약 · 2026-09-11

v5의 **커버 적중 = 안타**를 유지하며 런 성장이 플레이 행동의 가치를 바꾼다. 기다림은 스트라이크를 감수한 한 존 장타, 연결은 아웃을 투자한 다음 타석, 행운은 약한 단타의 누적과 추가 진루다. 단순 공격력 숫자 상승만으로 세 경로를 구분하지 않는다.

네 승부/세 보상에서 심화 또는 혼합한다. 성장마다 관련 카드가 보상 후보에 추가되며 기존 덱의 존 범위 선택과 결합한다. 자원 획득·예약·소모·잔여량과 효과를 플레이 전에 알려준다. 미리보기와 실제 결과는 같은 엔진을 사용한다.

실패 비용은 명시한다: 기다림은 미적중에도 소모, 연결은 다음 타석 한정, 행운은 다음 비홈런 안타에 소모한다. 초록 범위를 맞힌 안타를 다시 실패시키거나 일반 몹에 컨택 문턱 퍼즐을 되살리지 않는다. 재미와 최종 품질은 별도 플레이 검증 대상이며 기능 수로 완성이라 선언하지 않는다.

## 최우선 v5 설계 계약 · 2026-09-10

이 절은 아래 모든 역사 설계보다 우선한다.

**읽은 존을 맞혔으면 안타다.** 일반 몹의 필요 컨택 문턱과 적중 후 안타 실패 추첨은 폐기한다. 타자 타격/파워/행운과 투수 변화/구위/제구 비교는 땅볼 안타·중전안타·바가지 안타·장타의 비중만 조정한다. 낮은 스탯도 적중 보장을 취소하지 않는다.

READ → BET → REVEAL → IMPACT: 투구 경향과 기록 → 카드 커버와 존 선택 → 실제 공 공개 → 다음 공 또는 타자. 9존은 우타자 기준 왼쪽 몸쪽, 오른쪽 바깥. 9존 밖 볼은 별도 10번째 범주. 3개 덱과 각각 4개 숙련존, 기본 스윙, 명시적인 범위 표시로 카드 정답 보유 강제를 피한다.

카드는 세로/가로/십자/한 칸 타격 범위 또는 정보/준비를 제공한다. 넓은 범위는 타구 파워 페널티, 좁은 장타 카드는 파워 보너스. 준비·존 선택은 투구를 재추첨하지 않는다. PUBLIC은 TRUE INTENT의 실제 분포이며 임의로 거짓 확률을 표시하지 않는다.

한 공에 스윙은 한 번. 일반 파울·헛스윙은 같은 타석, 안타·볼넷·삼진·희생 아웃은 타석 종료. 결과 확인 전에 재입력 불가. 자동시뮬과 실플레이는 같은 engine.js를 사용한다. 엔진 규칙의 자동 검증은 재미의 인간 검증과 다르다.

기존 CQ/PQ 수치 및 ROOKIE/ADAPTER/FOX 명칭을 구현했다고 주장하지 않는다. 이번 버전은 타격 질/장타력 비교와 루키/싱커/외야 후퇴/이전 노림 반대편의 네 경향을 명시적으로 구현했다. 설계 세부·남은 한계는 DUEL.md v5 절 참고.

## 최우선 v3: 선수와 행동 카드를 혼동하지 않는다

타순은 선수 9명, 베이스 주자는 선수 ID, 덱은 행동 카드다. 한 공에 준비를 연계하고 최종 스윙은 한 번. 타석 판정이 끝나면 결과를 확인하고 다음 선수가 등장해야 행동이 다시 열린다. v2의 카드가 주자가 되는 규칙은 폐기. 세부 현재 규칙은 DUEL.md 첫 절.

## 최신 핵심 — HOMEBOUND v2

‘야구 스킨을 입힌 슬더스’를 거절한 사용자 피드백에 따라 HP/방어/3에너지 구조를 제거했다. **베이스는 덱의 일부이고, 득점은 카드 귀환이다.** 성공한 타격 카드를 일시적으로 잃으며 다른 카드로 진루시켜 회수한다. 대주자·주루·희생·장타가 카드 순환과 아웃·카운트를 서로 교환한다. 승리 조건은 3아웃 전 득점. 같은 원본 엔진/화면에 통합했고 최신 세부 규칙과 검증은 DUEL.md 첫 절. 아래 DUGOUT은 역사 기록이다.

## 최신 정의: DUGOUT / ACT 0

현행 설계는 [DUEL.md](./DUEL.md). 코스를 찍는 게임이 아니라 공개된 의도를 여러 카드의 순서와 조합으로 해결하는 턴제 로그라이크 덱빌딩 + 도트 그래픽이다. 우선 1투수/12카드/4전투/3보상. 30분 런과 분기 지도는 핵심 전투의 인간 검증 뒤 확장한다. 이전 숙련존/CQ/PQ/PUBLIC 확률을 되살리지 않는다. 아래는 이전 정의다.

## 현행 제품 정의 · LAST LIGHT

2026-09-09 사용자의 제로베이스 재개발 요청이 아래 기존 구현 지침보다 우선한다. 새 게임의 확정 설계와 변경 위치는 `docs/REBOOT.md`에 기록한다.

- 유지하는 감정은 “투수를 읽고 위험을 감수한다”뿐이다. 기존 UI·판정식·카드 구조를 답습할 의무가 없다.
- 3명의 투수, 각 3개의 공격 이닝. 실제 진루와 득점으로 목표 1/3/4점을 달성한다.
- READ는 위치 선택, BET는 독립된 타격 카드와 집중 위험 베팅, REVEAL은 선결정 투구 공개, IMPACT는 접촉/타구 질의 두 단계다.
- 기본 스윙 무제한, 시작 4숙련존, 손패 4장, 덱 10장. 새 숙련존과 영구 능력 보상이 이닝 사이의 성장이다.
- 새 seeded engine 하나를 UI와 정책봇이 공유한다. 현재 선택을 보고 AI 투구가 바뀌지 않는다.
- 30분은 타이밍 가정으로 명시하고, 실제 사람의 플레이 검증 없이는 달성했다고 주장하지 않는다.

## 이전 설계 배경 (현행 규칙과 충돌하면 위 정의가 우선)

> 무엇을 만드는가를 기록하는 초기 기획서다. 큰 방향이 바뀔 때만 수정한다.

## 한 문장 정의

- 공개 확률과 투수의 반복 습관을 함께 읽고, 틀릴 위험을 감수해 한 존에 베팅하는 9존 야구 심리전이다.

## 플레이어가 느껴야 하는 핵심 감정

- 최고 확률을 고른 안도감보다 “내가 저 투수를 읽었다”는 확신과 적중의 쾌감.
- 실패해도 운 탓으로 끝나지 않고, 다음 공의 역심리와 새 패턴을 생각하게 되는 긴장감.

## 핵심 플레이 흐름

1. **READ** — PUBLIC 확률, 카운트, 앞선 투구 기록, 투수 성향에서 다음 위치를 추론한다.
2. **BET** — 한 존, 인접 두 존, 존 카드와 수식어, 또는 BASIC SWING 중 위험과 보상을 고른다.
3. **REVEAL** — 숨겨진 TRUE INTENT에서 나온 실제 공을 공개하고 읽기의 정확도를 판정한다.
4. **IMPACT** — 읽기 결과를 CQ와 PQ에 반영해 접촉과 타구의 질을 순서대로 결정한다.

## 반드시 지킬 설계 원칙

- READ와 HIT를 같은 결과로 만들지 않는다. 정확히 읽고도 실패할 수 있고 오독에도 뜻밖의 안타가 나올 수 있다.
- PUBLIC은 판단 재료이고 TRUE INTENT는 숨은 실제 의도다. TRUE 수치를 UI에 직접 누설하지 않는다.
- POWER는 정확한 READ에서만 큰 장타 보상을 주고, 오독에는 더 큰 접촉 대가를 준다.
- 카드가 없는 존도 BASIC SWING으로 선택할 수 있게 하되 숙련과 덱 성장의 가치는 유지한다.
- 실제 경기, 동료 자동시뮬, 정책봇은 같은 CQ/PQ 엔진과 투구 모델을 사용한다.
- 봇 시뮬레이션은 지배전략을 찾는 회귀 도구로 쓰고, 재미의 최종 판단은 인간 플레이테스트로 한다.

## 하지 않을 것

- TRUE INTENT 수치나 숨은 AI 판단을 결과 화면에 공개하지 않는다.
- 연속 READ 횟수를 공격력 배율로 바꾸지 않는다.
- 현재 선택한 카드나 존을 AI가 미리 읽어 대응하게 만들지 않는다.
- 공용 판정식을 화면, 자동시뮬, 정책봇에 복사해 서로 다른 규칙을 만들지 않는다.
- 코어 감정이 인간 플레이테스트로 검증되기 전에 카드와 기능을 대량으로 늘리지 않는다.

## 2026-09-09 범위 확장: 약 30분의 완결된 런

사용자가 실제 런을 요청했으므로 기존 한 타석 검증에 더해 THE NIGHT RUN을 구현한다. 인간 재미 검증이 완료됐다는 뜻은 아니다. 기존 카드와 자산을 재사용하고 성장 선택을 세 가지로 제한한다.

- 6라운드 × 8타석, ROOKIE/ADAPTER/FOX 각 2회. 유저가 모든 타석을 친다.
- 라운드 목표 3/4/4/5/5/6루, 도전 기회 3, 중간 실패 시 기회 소모 후 진출, 최종전은 반드시 목표 달성.
- 시작 4숙련존, 덱 10장, 기본 손패 5장. 다섯 보상에서 숙련존 추가·카드 강화·회복 중 택일.
- 공개 확률과 실제 투구를 분리한다. 압축 전술도 PUBLIC의 관찰 노이즈만 제거한다.
- 저장은 완료된 판정의 체크포인트다. 미공개 실제 투구나 TRUE 분포는 저장하지 않는다.
- 12구 장기 타석은 볼넷 처리한다. 시간 끌기 대신 명시적 규칙으로 종료를 보장한다.
- 목표 25–35분. 실측 이전에 30분 체험이나 재미가 검증됐다고 표현하지 않는다.
