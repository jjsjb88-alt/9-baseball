# 투수 SD 로스터 v2

레드 러시를 제외한 기존 투수 로스터 **11명 전원**의 화면 왼쪽 방향 투구 에셋이다. 캐릭터마다 외형이 다른 투명 원본 자세 시트 2장(총 12개 원화 자세), 256×256 투명 프레임 120개를 담은 10열×12행 PNG 아틀라스 1장, 미리보기 GIF와 매니페스트를 제공한다. 경로의 전투·강적·보스에 티어별 투수를 배정하고 전투, 경로 미리보기, 보상 화면에서 각 아틀라스와 원화를 사용한다.

- `source/<id>-keys.png`: 세트, 코일, 레그 킥, 스트라이드, 릴리스, 팔로스루.
- `source/<id>-bridges.png`: 자세 사이의 손/다리/체중 이동을 위한 추가 원화 여섯 개.
- `atlases/<id>-pitch-120-atlas.png`: 60fps로 2초 재생하는 120프레임 아틀라스. 릴리스는 프레임 79다.
- `previews/<id>-poses.png`, `previews/<id>-pitch.gif`: 12개 원화 자세와 축소 재생 확인용.
- `<id>-manifest.json`: 방향, 프레임 크기, 타이밍, 원화 자세 위치.
- `preview.html`: 11명을 동시에 확인하고 프레임을 직접 움직일 수 있는 로컬 갤러리.

기존 캐릭터의 유니폼·머리색·장비 실루엣을 유지하면서, 참고 이미지의 일반적인 SD 비율과 픽셀 밀도만 참조해 새 포즈를 만들었다. 얼굴과 공은 화면 왼쪽 타자를 향한다. 오른쪽 방향은 게임에서 전체 프레임을 수평 반전하면 된다.

`scripts/build-pitcher-roster-sd.py`가 원본 시트에서 인물 실루엣을 분리해 120장을 다시 만든다. 팔이나 신발이 시트 칸을 넘는 포즈도 잘리지 않도록 연결된 투명도 영역을 추출한다. 12개 원화 자세 사이에서는 작은 몸통 축 이동과 회전을 매 프레임 적용하며, 광학 워프나 반투명 이중 노출은 쓰지 않는다. 따라서 120개의 비트맵은 모두 다르지만 **120개의 독립적으로 그린 원화는 아니다**. 원화를 더 추가해 동작의 부드러움을 끌어올릴 수 있도록 시트와 빌드 스크립트를 함께 남긴다.

```powershell
python scripts/build-pitcher-roster-sd.py
# 개별 프레임 PNG가 필요한 경우에만
python scripts/build-pitcher-roster-sd.py --loose-frames
```

코발트 임팩트와 네온 트릭의 반대 방향 준비 자세는 빌드 시 좌향으로 보정한다. 일부 원본 자세에는 공을 든 손의 연속성이나 팔 형태에 추가 검수가 필요한 컷이 있어 후속 아트 수정 대상으로 남아 있다.
