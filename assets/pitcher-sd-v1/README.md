# 레드 러시 SD 투구 애니메이션 v1

기존 [레드 러시 전신 원화](../pitcher-mobs-v1/regular-01-red-rush.png)를 식별할 수 있도록 붉은 고포니테일, 검은 모자와 붉은 엠블럼, 호박색 눈, 검정·진홍 유니폼, 아이보리 쇼츠, 갈색 글러브를 유지했다. 투수는 화면 오른쪽에서 **왼쪽 타자 방향**을 보고 공도 왼쪽으로 던진다. 참고 이미지의 일반적인 SD 비율과 픽셀 덩어리 표현만 연구했으며 캐릭터 디자인은 새로 제작했다.

- `source/`: image_gen으로 직접 만든 투명 원본 자세 시트 6장(총 36칸). 인게임 순서에는 그중 고유 자세 32개를 34번 배치한다.
- `frames/`: 256×256 투명 PNG 120장. 직접 제작한 자세에서 60Hz로 몸의 미세한 축 이동과 회전을 샘플링했다. 120장을 모두 개별 렌더링하며 중복 비트맵이 없음을 검사한다. 시트 칸 경계에서 넘어온 분리 픽셀은 생성 단계에서 제거한다.
- `red-rush-pitch-120-atlas.png`: 10열×12행, 2560×3072 단일 아틀라스. 런타임은 이 파일 하나를 불러온다.
- `red-rush-pitch-preview.gif`: 2초 투구 흐름의 축소 미리보기.
- `manifest.json`: 프레임 수, 방향, 아틀라스 규격, 키포즈 타임라인.
- `scripts/build-pitcher-sd-120.py`: 동일 결과를 재생성하는 스크립트. Pillow 필요.

와인드업→코일→무릎 들기→손 분리→발 디딤→오른팔 릴리스→팔로스루→복귀로 이어진다. 픽셀 아트의 손발이 찢어지는 광학 워프와 반투명 이중 노출은 최종 출력에 쓰지 않았다. 원본 시트는 리터치가 가능한 단계별 원화이며, 자동 생성 프레임은 실제 게임 크기에서도 계속 QA해야 한다.

## 코드 연결 전 영향도 분석

| 축 | 판단 | 대응 |
| --- | --- | --- |
| UI / 레이아웃 | 영향 있음 | 기존 투수 액터의 박스와 바닥 기준점을 유지한다. |
| 입력 / 제스처 | 영향 없음 | 렌더링만 변경하며 새 입력을 두지 않는다. |
| 게임 로직 / 밸런스 | 확인 필요 | 레드 러시의 외형 ID와 표시 이름만 상대 데이터에 추가한다. 투구 판정과 피해량은 바꾸지 않는다. |
| 저장 / 불러오기 | 영향 있음 | 새 artId는 선택 사항으로 읽고 과거 세이브에는 기존 투수 스프라이트를 적용한다. |
| 모바일 뷰포트 | 영향 있음 | 아틀라스를 액터 박스에만 그리며 세로·가로의 기존 크기를 유지한다. |
| 스크롤 / 오버플로 | 영향 없음 | 전역 높이·오버플로·위치 규칙을 수정하지 않는다. |
| 기존 사용자 플로우 | 확인 필요 | 레드 러시 상대가 있는 새 런, 과거 세이브의 다른 상대, 보상으로 이어지는 흐름을 검증한다. |
| 테스트 / 회귀 | 영향 있음 | 120개 프레임의 투명도·고유성·아틀라스 배치, 상대 ID·타임라인 테스트를 추가한다. |
| 빌드 / 배포 | 영향 있음 | 게임은 아틀라스 한 장만 import한다. 전체 PNG는 편집 원본으로 남기고 production build 및 스모크를 검사한다. |
