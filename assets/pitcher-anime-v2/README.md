## 참고 범위

참고 대상은 큰 눈의 표현, 단순한 작은 입과 코, 머리카락의 넓은 하이라이트, 단계적인 픽셀 명암, 섬세한 도트 밀도 같은 일반적인 표현 기법이다. 참고 캐릭터의 얼굴 정체성, 헤어·의상·장식의 고유한 조합, 상징, 설정은 복제하지 않도록 설계했다. 참고 원본 이미지는 이 에셋 폴더에 재배포하지 않았다.

청록 시안의 수정 과정에서는 사용자가 제공한 회색 머리 초상을 렌더링 기법 참고로만 지정했고, 새로 만든 청록 투수의 독자적인 외형을 유지하도록 지시했다. 다른 두 시안은 독자 디자인을 텍스트로 명세하여 생성했고, 갈색 머리 시안은 자체 생성 이미지를 편집해 상단 여백을 보완했다.

이는 유사성을 낮추기 위한 제작 방침이며 저작권 무침해의 법률 판정이나 보증은 아니다. 미국 저작권청은 일반 아이디어와 구체적인 표현을 구분하며, 충분히 독창적인 캐릭터의 시각 표현도 보호될 수 있다고 안내한다. 출처: https://copyright.gov/comp3/chap900/ch900-visual-art.pdf 및 https://www.copyright.gov/help/faq/faq-general.html
