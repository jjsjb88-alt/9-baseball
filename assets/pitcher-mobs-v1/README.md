## 제작 기준

- 전원 명백한 성인 여성. 성숙한 얼굴과 성인 체형, 선수다운 자세를 유지한다.
- 크롭 유니폼, 쇼츠, 몸에 맞는 긴바지, 자신감 있는 표정과 도발적인 태도로 매력을 표현한다.
- 얼굴·눈매·키·근육량·곡선·피부색·헤어·의상·투구 리듬을 함께 차별화한다. 색상만 바꾼 캐릭터를 별도 인물로 세지 않는다.
- 일반 몹부터 매력이 있어야 한다. 강적은 강한 배색과 자세, 보스는 독자적인 실루엣과 전용 장비로 구분한다.
- 고밀도 애니메이션 도트와 큰 눈, 작은 입·코, 윤기 있는 헤어를 기준으로 한다. 야구 장비와 축발·손 방향도 읽혀야 한다.
- 독자적인 캐릭터 디자인을 명세했다. 참고 캐릭터의 고유한 얼굴·의상·장식 조합을 복제하지 않는다. 청록 미라주의 신발에 생긴 브랜드를 연상시키는 표시는 사각 패널로 수정했다.

## 실제 게임과 대응

현행 src/duel/run-map.js의 battle / elite / boss, outside / sinker / high / closer 구조에 맞춘 디자인 매핑 제안이다. 1막 보스는 sinker, 2막은 high, 3막은 closer다. 게임 코드·수치·기존 이름 목록은 아직 변경하지 않았다.

현행 코드 주석은 한 런의 전투 칸을 최대 23개로 설명한다. 12명은 첫 제작분이므로 많은 인물을 만나게 하려면 추가 제작과 등장 중복 제어가 필요하다. 캐릭터별 고정 ID·얼굴·유니폼·팔레트·투구 리듬을 묶어 확장한다.

## 파일과 상태

내장 image_gen으로 제작한 전신 디자인 원본 PNG 12종이며 생성 파일을 변경 없이 복사했다. PROMPTS.md에 정확한 최종 프롬프트, roster.json에 분류/성향, qa.json에 이미지 크기와 알파 검사를 기록한다.

현재 각 캐릭터는 한 장의 키포즈다. 게임 렌더러 연결·출현 빈도·중복 방지·통일된 픽셀 격자와 팔레트·발 기준점·투구 애니메이션은 아직 적용하지 않았다. 상단 여백이 좁은 원본은 실제 아틀라스 제작 시 충분한 공통 패딩을 확보한다.

다음 캐릭터별 제작 단위는 set / windup / release / follow-through / reaction / defeat와 얼굴 초상이다. 현재 한 장을 반복해 완성 애니메이션이라고 부르지 않는다.
