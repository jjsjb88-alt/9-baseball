## 현재 로컬: v8 · 읽히는 투수, 벌어서 보는 확률 (2026-09-13)

투수가 9존을 처음부터 다 쓰지 않는다. **좁게 시작해서 넓어진다.** 그리고 존 확률은
처음부터 숫자로 보이지 않는다. **명암 → 구간 → 정확한 값** 순으로 올라가며, 그 등급을
덱의 관찰 카드와 유물이 올린다. 아래 v7 절보다 이 절과 [덱 설계](./docs/DECK.md) §8–§9가 우선한다.

**아직 배포하지 않았다.** 공개 사이트는 v6이다.

- 루키는 4존으로 시작해 6존까지, 마무리는 7존으로 시작해 9존까지 넓힌다. 2타석마다 한 존씩.
  2스트라이크에서는 두 존을 더 뻗었다가 카운트가 풀리면 돌아온다.
- 레퍼토리 밖 존의 확률은 **정확히 0**이다. 낮은 게 아니라 던지지 않는다.
- 관찰 점수(덱의 관찰 카드, 강화는 2점)가 0~1이면 명암만, 2~3이면 5% 구간, 4 이상이면 정확한 값.
  **세 시작 덱 모두 1점이라 모든 런은 명암만 보이는 상태로 시작한다.**
- 유물 3종 — 낡은 망원경(등급 +1) / 투구 기록장(볼 확률만 항상 정확) / 구속 판독기(안 쓰는 존 확정 표시).
  보상에서 카드 추가·제거·강화와 **경쟁한다**.
- **낮은 등급은 숫자를 감출 뿐, 틀린 숫자를 보여주지 않는다.**
- 버그 수정: 시작 조준이 투수가 한 번도 던지지 않는 존을 겨누고 있었다.

### 측정 (270런, v7 → v8)

**이 숫자는 체감 난이도가 아니다.** 정책 봇은 읽기 등급을 무시하고 정확한 확률을 읽으므로,
188/270은 *정보를 완전히 갖춘* 플레이어의 상한이다. 명암만 보이는 런이 이만큼 쉽다는 뜻이 아니다.

## 과거 로컬: v7 · 덱을 설계하는 화면 (2026-09-12)

카드를 "작은 명령 버튼"이 아니라 **덱의 부품**으로 보이게 고쳤다. 간단하게 누르는 게임이 아니라
복잡한 조합을 쉽게 비교하는 게임으로 가는 작업이다. 아래 v6 및 이전 기록보다 이 절과 [덱 설계](./docs/DECK.md)가 우선한다.

**아직 배포하지 않았다.** 공개 사이트는 v6이다.

- 손패의 모든 카드가 **역할 · 커버 축 · 산출**(가로 3존 커버 / 파워 +18 / 주자 2베이스 …)을 항상 표시한다.
- 지금 실제로 맞물리는 카드에 **연계·상충 이유**가 함께 뜬다. 릴리스 간파를 쓰면 가로 3존 카드에
  "확인한 높이의 가로 3존 — 적중 확정"이 붙는다. 눌러서 외울 필요가 없다.
- 상충도 같은 비중으로 표시한다. 좋은 조합만 보여주면 다시 정답 누르기가 된다.
- 보상이 후보 나열이 아니라 **내 덱을 먼저 보여준다.** 범위 구성·역할 분포·준비:스윙 비율과 진단 문장이
  뜨고, 후보를 고르면 변화량과 해소되는 지적이 함께 표시된다.
- 보상 행동이 넷이다: **카드 추가 / 제거 / 강화 / 덱 그대로.** 한 보상에 하나만 고른다. 덱 9~18장.
- 강화(`+`)는 범위·파워·정보·진루만 바꾼다. **커버 안의 공을 아웃으로 되돌리는 강화는 없다.**
- 성장이 지정 카드로 굳지 않는다. 시그니처 고정을 없애고 성장마다 세 방향 후보 축을 준다.

### 연결 경로 수정

v6에서 연결 성장의 시그니처는 희생 번트로 고정돼 있었다. 번트는 안타가 나오지 않는 카드이고
3아웃 제한에서 아웃을 지불한다. 270런 자동 정책에서 **5/90 완주**였다.

| 시작 덱 | 기다림 | 연결 | 행운 |
| --- | ---: | ---: | ---: |
| 몸쪽 장타 | 8/30 (v6 8) | **8/30** (v6 0) | 15/30 (v6 15) |
| 바깥 연결 | 15/30 (v6 15) | **16/30** (v6 0) | 20/30 (v6 20) |
| 끈질긴 컨택 | 25/30 (v6 25) | **22/30** (v6 5) | 26/30 (v6 26) |

기다림 48/90과 행운 61/90은 v6과 **셀 단위로 같다.** 바뀐 것은 연결뿐이다(5/90 → 46/90).
다른 경로를 건드리지 않고 원인만 제거했다는 뜻이다.

측정 도중 기다림 후보 축에서 관찰 카드를 빼자 48/90 → **15/90**으로 무너졌다. 기다림은 *지켜본*
스트라이크로 충전되므로 정보 카드가 그 성장의 전제다. 후보 축에 관찰을 되돌렸다.
